# 아차사고 사례 자동 분류기

키워드를 넣으면 뉴스를 자동으로 찾아 아차사고 기준으로 분류하고, 근거와 링크가 붙은 표와 보고서 초안(워드 파일)을 만들어 주는 앱이에요. 담당자 1명이 쓰는 앱이고, 내 컴퓨터에서 돌리거나 Vercel에 **앱 비밀번호를 걸어** 배포해 쓸 수 있어요. 아차사고(대형 재난으로 이어질 뻔한 사례)를 모으고 정리하는 일을 돕는 연습용 프로젝트예요.

자세한 내용은 [PRD.md](PRD.md)(기획), [PLAN.md](PLAN.md)(작업 계획), [DESIGN.md](DESIGN.md)(설계)를 보세요.

## 1. 준비물

- **Node.js** (LTS 버전)와 **Git**
- **OpenAI 키**: 분류와 보고서를 쓰는 AI에 필요해요.
- (선택) 네이버 검색 API 키: 없으면 구글 뉴스로 검색해요.

## 2. 처음 한 번: 설치와 키 넣기

터미널에서 이 폴더(`my-app`)로 이동한 뒤 설치해요.

```bash
npm install
```

폴더에 `.env` 파일을 만들고 아래 이름으로 한 줄씩 값을 넣어요. (값은 `=` 뒤에 붙여서 쓰고, 따옴표와 공백은 넣지 않아요.)

```
OPENAI_API_KEY=여기에_키
NAVER_CLIENT_ID=선택
NAVER_CLIENT_SECRET=선택
```

- `.env`는 비밀 값 파일이라 **git에 올라가지 않아요.** 메신저·메일로 보내거나 화면 공유로 보여주지 마세요.
- 네이버 키 두 줄은 **없어도 돼요.** 둘 다 넣으면 네이버 검색을, 없으면 구글 뉴스 검색을 써요.

## 3. 실행하기

```bash
npm run dev
```

브라우저에서 **http://localhost:3000** 으로 들어가세요. (3000번이 이미 쓰이면 화면에 나온 다른 번호를 쓰세요.)

- `npm run dev`와 `npm start`는 **이 컴퓨터에서만** 열리게 설정돼 있어요(`package.json`의 `-H 127.0.0.1`). 같은 와이파이·사내망의 다른 사람은 주소를 알아도 접속할 수 없어요. 이 앱에는 로그인이 없으니 이 설정을 지우지 마세요.
- 끄려면 터미널에서 `Ctrl + C`를 눌러요.

## 4. 쓰는 순서

1. **키워드 입력** → "연관검색어 보기"를 눌러요.
2. 검색에 쓸 검색어를 **최대 10개** 고르고 "뉴스 검색·분류하기"를 눌러요. (20건까지, 시간이 조금 걸려요.)
3. 분류 표를 보고, 링크로 원문을 확인한 뒤 결과마다 **적합 / 추가검색필요**를 눌러요. 이 표시가 쌓여 "적합 비율"이 계산돼요.
4. 보고서로 쓸 사고를 **하나** 고르고 "선택한 사고로 보고서 초안 만들기"를 눌러요.
5. "워드로 내보내기"를 눌러 보고서와 분류 표를 `.docx` 파일로 저장해요. 보고서는 **센터 양식**(사고개요 → 사고발생 경위 → 아차 사고 지점 및 대형 사고 발생 가능성)으로 나와요. **분류 결과는 새로 고치면 사라지니, 남기려면 이때 내보내세요.**

**뉴스 검색 없이 글로 바로 보고서 만들기:** 키워드 칸 아래의 "또는 글을 붙여넣어 바로 보고서 만들기"에 기사 본문, 현장 보고, 대화 내용을 붙여넣고(최대 20,000자) "이 글로 보고서 초안 만들기"를 눌러요. "문제 삼으려는 지점"(선택)을 적으면 그 지점 중심으로 써요. 글에 없는 내용은 "확인 불가"로 나와요. 이름이나 연락처는 지우고 붙여넣는 것을 권해요. 처음 써 보려면 **"가상 예시 불러오기 (시험용)"** 버튼을 눌러 보세요. (`sample-data/virtual-tunnel-accident.md`, 모두 지어낸 가상 사례예요.)
위쪽 메뉴의 **관리 화면**에서는 아차사고 선정 기준과 분류 체계를 고치고 변경 이력을 볼 수 있어요. 고친 내용은 그 뒤의 검색·분류부터 적용돼요.

## 5. 기록 파일과 백업

표시 기록과 설정은 이 폴더의 **`data/`** 폴더에 저장돼요. (`marks.json`, `settings.json`)

- `data/`는 git에 올라가지 않아요. (`marks.json`은 표시 기록, `settings.json`은 설정, `recent.json`은 최근 검색한 기사 목록이에요.)
- 표시 기록은 기사 **2000건**까지 저장돼요. 가득 차면 기록을 지우지 않으려고 새 표시가 멈추니, 그때는 `data/` 폴더를 백업한 뒤 정리하세요.
- 컴퓨터를 바꾸거나 폴더를 지우면 기록이 사라져요. **가끔 `data/` 폴더를 통째로 복사해서 백업**해 두세요.
- 파일을 직접 열어서 고치다가 형식이 깨지면 기록이 초기화될 수 있으니 직접 고치지 마세요.

## 6. 잘 되는지 확인하기

```bash
npm run lint
npm run build
```

둘 다 오류 없이 끝나면 코드는 정상이에요. 연습용 가상 데이터(`sample-data/` 폴더)로 보고서 모양을 미리 볼 수도 있어요.

## 7. 알아 둘 점

- 구글 뉴스 검색은 요약이 거의 없어서 **제목 위주로** 분류해요. 판정은 AI가 하는 것이라 틀릴 수 있으니, 꼭 링크로 원문을 확인하세요.
- 보고서는 **초안**이에요. 담당자가 확인하고 다듬어 쓰세요.
- 키워드 칸에 사람 이름 같은 개인정보는 넣지 마세요. 입력한 키워드와 기사 제목은 외부 AI와 검색 서비스로 전달돼요.
- AI 사용에는 비용이 들어요. OpenAI 관리 페이지에서 **월 사용 한도**를 정해 두는 것을 권해요.
- 이 저장소는 공개돼 있어요. 키·비밀번호는 코드에 없고 `.env`와 Vercel 환경변수에만 있어요.

## 9. 인터넷에 배포하기 (Vercel)

1. Vercel에서 이 저장소를 가져오거나 Vercel CLI로 배포해요.
2. 환경변수 **`OPENAI_API_KEY`** 와 **`APP_PASSWORD`**(긴 비밀번호)만 등록해요. GitHub·Vercel 토큰 같은 관리용 값은 등록하지 마세요.
3. 접속하면 브라우저가 비밀번호를 물어요. 아이디는 아무거나, 비밀번호는 `APP_PASSWORD` 값이에요. `APP_PASSWORD`가 없으면 접속이 막혀요(503).
4. 배포본은 서버의 **임시 폴더**에 저장해서, 서버가 한동안 쉬거나 다시 시작하면 표시 기록·설정이 초기화될 수 있어요. 오래 남길 기록은 내 컴퓨터판을 쓰세요.
5. 시도 횟수 제한이 없으니 비밀번호를 길게 쓰고 OpenAI **월 사용 한도**를 정해 두세요. 구글 뉴스 검색이 Vercel 서버에서 되는지는 배포 후 확인이 필요해요.

## 8. 폴더 안내

| 폴더·파일 | 내용 |
|---|---|
| `app/` | 화면과 서버 주소(API) |
| `lib/` | 뉴스 검색, AI 호출, 저장, 워드 만들기 |
| `data/` | 표시 기록과 설정 (실행하면 생겨요) |
| `sample-data/` | 연습용 가상 데이터 |
| `.env` | 비밀 키 (직접 만들어요) |
| `PRD.md` `PLAN.md` `DESIGN.md` `CLAUDE.md` | 기획, 계획, 설계, 작업 규칙 |
